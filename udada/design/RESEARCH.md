# 우다다 디자인 공부 노트

## 1. 앱 이해 (일지 4건 기준)

| 항목 | 내용 |
|---|---|
| 누구 | 숏폼(쇼츠·릴스) 중독, 머리가 과부하. 할 일이 쌓였는데 시작을 못 함 |
| 핵심 동작 | 머릿속 쏟아내기 → AI가 2~10분 **클립**으로 자름 → 세로 전체 화면 피드에서 한 장씩 |
| 숏폼 문법 재사용 | 위로 밀기 = **끝냈다**(넘기기 아님), 오른쪽 아이콘 줄, 진행 막대, 두 번 톡 |
| 보상 | XP·콤보(최대 ×1.5)·15% 크리티컬·쉬는 시간·칼복귀 +30·레벨 |
| 보조 | 막힘 → 1~3분 조각으로 다시 자름 / 생각남 → 인박스 / 위기 시트(109) |
| 원칙 | 한 화면 한 가지. 피드·알림·연속기록 압박 없음. 의도는 앱이 기억 |

### 지금까지 거절된 디자인과 이유
- **v1** 어두운 배경 + 분홍·주황 그라데이션 + 빛 번짐 + 색종이 + 알약 버튼 → "AI slop 같다"
- **v2** 단색 포스터 + 칭찬 도장 → 숏폼처럼 안 생김, 정적, 도장과 숏폼 문법이 따로 놂
- **v3** 리소 그림 + 테두리 자막(현재) → 종이 톤은 좋지만 "그림 보는 앱"이 되어 버림. 할 일이 주인공이 아님

→ 교훈: **장식이 아니라 은유(metaphor)가 화면 구조를 정해야** 한다. 은유가 숏폼 문법(밀기·진행 막대·연속 재생)과 맞물려야 한다.

## 2. AI slop 의 지문 (피해야 할 것)

출처: 925studios "AI Slop Fonts and Gradients"(2026.6), Designpixil "AI Slop"(2026.9, 832개 사이트 조사 — Lovable 앱 40%가 기본 표식 3개 이상, YC 스타트업은 8%), Anthropic cookbook "Prompting for frontend aesthetics".

1. 남색→보라 그라데이션 (Tailwind `indigo-500` 기본값이 학습 데이터를 점령 — Adam Wathan 공개 사과)
2. Inter/Geist/Roboto 한 가지로 모든 크기 — 제목과 본문의 목소리 차이가 없음
3. 같은 폭 둥근 카드 3개 + 얇은 회색 테두리 + 선 아이콘
4. 모든 면에 같은 8px 둥근 모서리, 같은 그림자 → 위계 없음
5. 전부 가운데 정렬
6. 글래스모피즘·빛 번짐·그라데이션 덩어리가 실제 내용 대신 자리를 채움
7. 섹션마다 알약 배지, 이모지 아이콘
8. 문구가 3단: "빠르게. 쉽게. 똑똑하게." / "seamlessly", "unlock", "elevate"
9. 색종이·반짝이 같은 '기본 축하' 효과

> 핵심: 못생긴 게 문제가 아니라 **아무도 결정하지 않은 것**이 문제. 해결책은 제약 — 실제 브랜드 결정을 먼저 내리고 그 안에서만 만든다.

## 3. "촌스럽다"의 지문 (한국 맥락)

- 색이 많고 채도가 다 높음(원색 5개 이상이 같은 무게)
- 글자에 그라데이션·외곽 그림자·3D 효과, 기울인 굵은 글씨
- 의미 없는 클립아트·3D 이모지·캐릭터 남발
- 정보가 빽빽하고 여백·정렬 기준선이 없음
- 트렌드를 반만 따라감(어설픈 글래스, 어설픈 네온)

반대로 세련됨 = **색은 적게, 크기 대비는 크게, 정렬선은 엄격하게, 하나의 은유를 끝까지**. 토스·당근이 촌스럽지 않은 이유도 "한 화면 한 메시지 + 절제된 색 + 큰 숫자"이다.

## 4. 2026 흐름 중 쓸 만한 것

- **촉감 있는 실물감(tactile realism)**: 평면 디자인의 '누를 수 있나?' 불확실성 반동. 버튼이 물리적으로 눌리는 느낌. (BuiltUX "Is flat design dead?")
- **문화적 레퍼런스에서 팔레트를 가져오기** (Anthropic cookbook 권장: IDE 테마·문화 미학)
- **실제 내용이 곧 그래픽**: 장식 그림 대신 숫자·타이머·할 일 텍스트가 화면을 채움
- **한 가지 강조색** + 낮은 채도 바탕
- 마이크로 인터랙션은 "여기저기 조금"이 아니라 **한 순간을 제대로**(끝냈을 때)

## 5. 경쟁/참고 앱에서 본 것

- Tiimo: 시각적 타임라인은 좋지만 "다음에 뭘 할지"는 안 정해 줌 → 우다다는 다음 한 장만 보여 주는 게 강점
- Finch: 귀여운 캐릭터 보상 → 우다다 사용자층에는 유치할 위험
- Structured: 타임라인 → 숏폼 중독자에게는 '목록'이 이미 부담

## 6. 시안 방향 (4개) — 각자 다른 은유

| 시안 | 은유 | 숏폼 문법과의 연결 | 끝냈을 때 |
|---|---|---|---|
| A. 녹화중 | 캠코더 뷰파인더 | 보는 쪽 → **찍는 쪽**. 클립 = 내가 찍는 장면 | 필름 롤에 클립 저장, 타임코드 정지 |
| B. 딩동 017번 | 은행·민원실 번호표 + 전광판 | 다음 번호가 불림 = 다음 클립 | 번호표가 뜯겨 날아감, 전광판 "처리 완료" |
| C. 답안지 | OMR 카드 + 시험지 | 한 문제씩 = 한 장씩, 남은 문항 = 진행 막대 | 컴퓨터용 사인펜으로 칸이 칠해짐, 빨간 채점 |
| D. 기계 | 손에 쥐는 장난감 기계(TE류) | 위로 밀기 = 큰 버튼 '딸깍' | 기계식 숫자판이 넘어감 |

공통 금지: 그라데이션, 글래스, 빛 번짐, 색종이, 이모지, 전 화면 같은 둥근 모서리, Inter/Roboto.
